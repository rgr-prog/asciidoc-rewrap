# Icon sources

The extension icon combines the original Rewrap artwork with a small Asciidoctor badge to identify AsciiDoc support.

- Rewrap artwork: `../vscode/logo.png` and `../docs/images/logo.svg`, inherited from [Rewrap](https://github.com/stkb/Rewrap) / [Rewrap Revived](https://github.com/dnut/Rewrap). Original artwork remains unchanged.
- Asciidoctor reference: `asciidoctor-logo.svg`, downloaded from [asciidoctor/brand — logo-fill-color.svg](https://github.com/asciidoctor/brand/blob/master/logo/logo-fill-color.svg). Official colors: carmine `#e40046` and white. See the [brand usage guidance](https://github.com/asciidoctor/brand#usage).
- Composite master: `asciidoc-rewrap-master.png`, prepared with image generation using both original marks as references.
- Packaged icon: `../vscode/asciidoc-rewrap.png`, exported at 256 × 256 pixels.

Thanks to the Rewrap and Asciidoctor contributors for their artwork and visual identity. The badge identifies format compatibility; this extension is maintained independently by Rogério Ferreira da Cunha.
